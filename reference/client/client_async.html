ClientAsync#

class pyaseba.client.ClientAsync#

Offers an asynchronous alternative to pyaseba.client.Client replacing methods that blocks (and typically takes wait_ms: int as argument) with coroutines.

The reset of the interface is identical to pyaseba.client.Client.
