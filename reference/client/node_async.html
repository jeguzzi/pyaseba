NodeAsync#

class pyaseba.client.NodeAsync(cached: bool = False)#

Asynchronous alternative to pyaseba.client.Node based on pyaseba.client.ClientAsync.

Replaces methods that blocks (and typically takes wait_ms: int as argument) with coroutines, like for example

>>> node = Node()
>>> await node.connect("tcp:port=33333")
True

>>> node.set("value", [1, 2, 3])
>>> await node.get("value")
[1, 2, 3]

>>> await node.wait("e")
True

>>> await node.close()

The reset of the interface is identical to pyaseba.client.Node.
